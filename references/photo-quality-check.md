# 제품 사진 품질 검수 — 단아쌤 상세페이지 스킬

> 📦 단아쌤 한국형 상세페이지 스킬 · https://shoppingmallschool.com

사용자가 제품 사진을 업로드하면 **자동으로 품질 검수**하고, 낮은 품질이면 사용자에게 분기를 묻는다. 흐릿한 사진을 그대로 reference로 쓰면 모든 섹션 이미지가 흐려져서 판매에 못 쓴다.

## 자동 체크 항목 (5가지)

업로드된 첫 사진을 분석할 때 다음을 확인:

| 항목 | 양호 | 재생성 권장 |
|---|---|---|
| **해상도** | 1024×1024 이상 | 800px 미만, 픽셀 깨짐 |
| **초점** | 제품이 선명함 | 흐릿함, 모션블러 |
| **조명** | 균일한 자연광·스튜디오광 | 어둡거나 그림자 강함 |
| **배경** | 흰색·단색·정돈됨 | 잡동사니, 산만함 |
| **각도** | 제품 정면 또는 의도된 각도 | 비뚤어짐, 잘림 |

5개 중 **3개 이상이 양호**면 그대로 사용. **3개 이상이 문제**면 분기 질문 발동.

## 분기 질문 (품질 낮을 때)

```
📷 업로드하신 사진을 살펴보니 다음 부분이 판매용으로 약합니다:

  - {{이슈1: 예. "조명이 어두워 디테일이 안 보임"}}
  - {{이슈2: 예. "배경에 잡동사니가 있어 산만함"}}

어떻게 진행할까요?

A. 사진을 reference로만 쓰고 깨끗한 이미지로 재생성 (추천)
   → 제품 외관(색·로고·형태·재질)은 그대로 유지, 조명·배경·연출만 개선
B. 더 좋은 사진을 추가 업로드한 뒤 다시 시작
C. 현재 사진을 그대로 사용 — 결과물에 '판매용 초안' 라벨 부착
```

### A 선택시 처리

이미지 생성 시 프롬프트에 다음을 강제 주입:

> "Use this image as a strict reference. Preserve the exact product shape, color, logo, and material as shown. Replace ONLY the lighting (use bright clean studio light), background (use white or soft gradient), and styling. Do NOT add unverifiable labels, certifications, ingredients, or claims. Result must be a clean ecommerce product visual ready for Korean marketplace."

### B 선택시 처리

업로드 대기. 사용자가 "그냥 진행"이라고 하면 A로 전환.

### C 선택시 처리

모든 출력물에 `판매용 초안 (실제 판매 전 깨끗한 사진으로 재제작 권장)` 워터마크/안내 추가.

## 사진 종류별 권장 업로드

진짜 판매용 페이지를 만들려면 다음 종류의 사진을 받으면 좋다 — 사용자에게 안내:

| 사진 종류 | 어디에 쓰임 | 우선순위 |
|---|---|---|
| 정면 패키지샷 | 히어로컷·제품 소개 | 필수 |
| 실물 단독샷 (패키지 X) | 디테일 섹션 | 필수 |
| 매크로 디테일 (소재·텍스처) | 텍스처 섹션 | 권장 |
| 옵션·컬러 옵션 | 컬러/구성 섹션 | 카테고리 따라 |
| 크기 비교 (손/일반물건과) | 사이즈 가이드 | 권장 |
| 사용 장면 | 시나리오 섹션 | 권장 |
| 라벨·성분·주의사항 (화장품·식품·유아) | 컴플라이언스 섹션 | 카테고리 따라 필수 |

사진 종류가 부족하면 부족한 컷은 reference 기반 재생성으로 채운다.

## 한 장만 받았을 때

가장 흔한 경우 — 사용자가 정면 패키지샷 1장만 줌. 그래도 진행 가능:

1. 그 1장을 모든 섹션 이미지의 reference로 사용
2. 각 섹션마다 다른 연출·배경 프롬프트로 다양화
3. 제품 외관은 12장 모두에서 동일하게 유지
4. 결과물 헤더에 "1장 사진 기반 재생성" 메모

## 사진 분석 결과 카드 형식

분석 결과를 사용자에게 보여줄 때 다음 카드 형식 사용:

```markdown
### 📷 제품 사진 분석 결과

**파일**: product.jpg (1280×1280)
**품질 평가**: 4/5 (양호)
  ✅ 해상도: 1280×1280 (충분)
  ✅ 초점: 선명
  ⚠️ 조명: 그림자가 한쪽으로 치우침
  ✅ 배경: 흰색·정돈됨
  ✅ 각도: 정면

**추출 정보**:
- 추정 카테고리: 🏠 생활용품
- 시각적 특징: 접이식, 검정+그레이 투톤, 메탈 프레임
- 보이는 소재: 옥스포드 천, 알루미늄
- 예상 USP: 트렁크 슬림 수납, 방수 원단, 10kg 견딤

**권장 사용 방식**: reference 모드 (외관 보존 + 연출 개선)
```
