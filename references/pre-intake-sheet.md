```

```

## 🚀 Codex에서 쓰는 법

1. 위 시트를 복사해서 빈칸 채우기 (메모장·노션·아무 데서나)
2. Codex 새 세션 시작
3. 시트 통째로 붙여넣고 한 줄 덧붙이기:
   > "이 정보로 상세페이지 만들어줘"
4. Codex가 인테이크 질문 건너뛰고 STEP 3(분석 결과 확인) 또는 STEP 5(카피 작성)로 바로 진행

## 채울 때 팁

- **A, B, C 3개만 채워도 됨** — 나머지는 사진 분석 + 제품명 추론으로 알아서 채워줍니다
- **USP가 가장 중요해요** — 비어있으면 일반론 카피가 나와요. 3~4개 적어두세요
- **타겟(H)이 정확하면 보이스톤 추천이 정확해짐** — 두 개가 짝이거든요
- **리뷰 엑셀(I)이 있으면 카피 진정성 ↑** — 가짜 후기 만들 일 없어요
- **사진 품질(N)** — 1번(재생성 권장) 추천. 원본 사진을 reference로 쓰되 깨끗하게 다시 만들어요

## 호스트 에이전트 지시 (Codex 자체용)

사용자가 이 시트 형식으로 입력하면 다음 룰로 처리:

1. **시트 감지** — `[A] 제품명:` `[B] 제품사진경로:` `[C] 보이스톤:` 패턴이 보이면 사전 입력 시트로 인식
2. **일문일답 인테이크 건너뛰기** — `references/intake-flow.md` 의 Q1~Q8 순차 진행 X
3. **빈 항목은 자동 추론** — D~M 비어있으면 사진·제품명·카테고리에서 추론, 추론한 값은 `(자동)` 라벨로 사용자에게 한 번 확인
4. **시트 파싱 결과 요약 후 진행** — "이렇게 이해했어요" 카드로 한 번 보여주고 OK 받으면 STEP 5(카피 작성)로 직행
5. **A, B, C 중 빠진 게 있으면** — 그것만 물어보고 나머지는 그대로 사용
