# Product Information Disclosure

The product information disclosure must be the absolute bottom cut for Coupang pages and any marketplace page where disclosure is needed.

## Intake

Ask whether the user can provide the disclosure as:

- Image
- Text
- Existing marketplace page capture
- Category and known fields only

If missing, create a category-appropriate disclosure draft with `확인 필요` in unknown fields. Do not invent required facts.

## Common Fields

Adapt fields by category, but commonly include:

- Product name
- Model name, if applicable
- Manufacturer/importer/seller
- Country of origin
- Material/ingredients/composition
- Size, capacity, quantity, or weight
- Manufacturing date or expiration date, if relevant
- Certification or report number, only if provided
- Caution, storage, use method, or handling guide
- Customer service/contact, if provided

## Category Sensitivity

For food, health supplements, cosmetics, medical devices, baby products, pet products, electronics, and household chemicals, ask for category-specific legal fields before final production. Mark missing fields as `확인 필요`.

## Image Design

The disclosure cut should be clean, readable, and table-like. It should not look like a sales claim section. Use small but mobile-readable Korean text, high contrast, and clear rows.
