# 인테이크 플로우 — 단아쌤 상세페이지 스킬

> 📦 단아쌤 한국형 상세페이지 스킬 · https://shoppingmallschool.com

사용자에게 **한 번에 하나씩** 질문하고, 매번 명시적 선택지를 제시한다. 이미 사용자가 답한 항목은 건너뛴다.

## 질문 1. 제품 사진 (필수)

```
📷 제품 사진이 있나요?

A. 있음 — 첨부한 사진을 기준으로 제작
B. 있음 — 곧 첨부할 예정
C. 없음 — 제품명·카테고리 기준으로 컨셉 초안 제작
```

- A: 사진을 reference로 사용. `references/photo-quality-check.md` 워크플로우 발동.
- B: 사진 업로드 대기. 사용자가 "그냥 진행해"라고 하면 C로 전환.
- C: 결과물에 **`판매용 초안`** 라벨. "실제 판매에는 진짜 제품 사진 권장" 안내.

## 질문 2. 진행 방식

```
🚀 어떻게 진행할까요?

A. 추천 자동 모드 — 핵심 정보만 입력하면 단아쌤 공식으로 알아서 진행 (15분)
B. 정밀 모드 — 카테고리·보이스톤·섹션마다 직접 선택 (25~30분)
```

- A 선택시: Q3~Q4(필수) + Q6(보이스톤)만 묻고 나머지는 자동.
- B 선택시: Q3~Q8 모두 묻는다.

## 질문 3. 카테고리

```
📦 어느 카테고리에 가까운가요?

A. 💄 화장품 — 피부·메이크업·헤어·향수 (12섹션)
B. 👜 패션잡화 — 가방·신발·액세서리·시계 (10섹션)
C. 🏠 생활용품 — 청소·수납·인테리어·DIY 도구 (9섹션)
D. 🍱 식품 — 가공식품·신선식품·간식 (11섹션)
E. 🔌 전자제품 — 가전·디지털·스마트기기 (11섹션)
F. 🧸 어린이용품 — 유아용품·완구·교육 (9섹션)
G. 🍳 주방용품 — 조리도구·식기·주방가전 (11섹션)
H. 🧴 세제 — 세탁·청소·욕실·주방 세제 (10섹션)
I. 👕 의류 — 상의·하의·아우터·내의 (10섹션)
```

사진 분석이 끝났으면 추천 카테고리에 `(추천)` 표시. 사용자가 다른 걸 고르면 그대로 따른다.

선택 직후 `data/categories.json` 에서 해당 카테고리 섹션 스키마 로드.

## 질문 4. 제품명 + 핵심 키워드

```
📝 제품 정보를 알려주세요.

A. 제품명 + 핵심 키워드 3~6개 (예: "차몰랑 세차의자 / 접이식, 방수, 트렁크수납")
B. 제품명만 (키워드는 사진·카테고리에서 추론)
C. 미정 — 추천 가정으로 진행
```

- 추출된 키워드는 후킹 카피에 직접 들어간다.
- 사용자가 명확한 USP를 줬으면 가격·옵션·타겟도 함께 받는다.

## 질문 5. 주요 고객 (보이스톤 결정과 연결)

```
👥 주요 고객은 누구인가요?

A. 20~30대 트렌디·DIY 셀프족
B. 30~40대 여성 라이프스타일 (가성비 + 편리)
C. 20~40대 남성 전문가·실용주의
D. 40대+ 고소득 프리미엄
E. 모든 연령 — 와디즈식 자극 후킹으로 어필
F. 직접 입력
```

각 답변은 보이스톤 추천으로 이어진다 (다음 질문에서).

## 질문 6. 보이스톤 (단아쌤 스킬 핵심!)

질문 5의 답에 따라 추천 1순위에 `(추천)` 표시.

```
🎭 카피 톤을 골라주세요.

A. 🔥 와디즈식 자극 — "아직도 ~ 쓰세요?" 강렬·긴박감 (FOMO)
B. 🧠 전문가·실용 — "효율 30% 단축" 수치·기술·신뢰감
C. 👑 프리미엄·고급 — "당신을 위한 단 하나" 세련·차분
D. ☕ 친근·라이프스타일 — "오늘부터 편해집니다" 가볍고 친근
E. ✨ 트렌디·활기찬 — "꿀템 등장" 활기·캐주얼·감성
```

보이스톤은 후킹 스타일·본문 어조·이모지 사용까지 결정한다. `data/voice-tones.json` 에서 상세 가이드 로드.

## 질문 7. 섹션 수 (선택)

```
📊 섹션 수를 조정할까요?

A. 카테고리 기본 ({{N}}섹션) — 추천
B. 빠른 6섹션 — 간단 상품용
C. 정밀 12~15섹션 — 고관여 상품·복잡한 설명 필요
```

기본값은 카테고리별 자동 (화장품 12, 생활용품 9 등). 다른 수 선택시 우선순위 낮은 섹션을 자동 제외하거나 분할.

## 질문 8. 리뷰 엑셀 (선택)

```
📑 리뷰 엑셀이 있나요?

A. 있음 — 첨부 (스마트스토어·쿠팡·자체몰 엑셀)
B. 없음 — 카피는 추론으로 진행
```

A 선택시 `scripts/parse_reviews.py` 호출 → 긍정 문장 30개 추출 → 카피 생성 컨텍스트에 포함.

## 질문 9. 판매 채널 (정말 필요한 경우만)

기본 가정: **채널 무관 모바일 상세페이지**. 사용자가 채널을 언급했거나 채널별 규정이 중요할 때만 묻는다.

```
🏪 어떤 채널에 올릴 건가요? (선택)

A. 채널 무관 모바일 상세페이지 (추천)
B. 스마트스토어 (SEO·검색 최적화 신경)
C. 쿠팡 (가격·배송·규정 강조)
D. 자사몰·브랜드몰 (스토리텔링 자유)
E. 인스타·광고 랜딩 (감성 + CTA 강화)
```

## 통합 원칙

1. **한 번에 하나만** — 8개 질문을 한꺼번에 쏟아붓지 않는다.
2. **명시적 선택지** — 자유 입력만 받지 않고 항상 A/B/C 옵션 제시.
3. **추론으로 답하기** — 사진/제품명에서 추론 가능한 답은 `(추천)` 표시로 미리 채워서 보여주고 사용자가 그대로 OK 하면 빠르게 진행.
4. **건너뛰기** — 사용자가 이미 준 정보는 다시 묻지 않는다.
5. **답변 매핑** — Q5(고객) 답이 Q6(보이스톤) 추천을 자동 결정해야 한다.
