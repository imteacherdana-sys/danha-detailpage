# 최종 이미지 품질 기준 — 단아쌤 상세페이지 스킬

> 📦 단아쌤 한국형 상세페이지 스킬 · https://shoppingmallschool.com

생성된 이미지는 **실제 마켓플레이스 상세페이지에 그대로 올릴 수 있는 수준**이어야 한다. 컨셉 아트나 와이어프레임이 아니다.

## 필수 요건 (모든 컷)

### 1. 한글 텍스트가 이미지에 직접 박혀야 함

- 짧은 후킹 카피(8~15자)는 이미지 안에 큰 글씨로 들어간다.
- gpt-image-2 멀티링구얼 렌더링이 한글을 잘 처리하지만, 만약 깨지면 **재생성** — 후처리 텍스트 오버레이로 패치 X.
- 본문(긴 한국어 3~5줄)은 HTML 텍스트로 분리. 이미지에 박지 않는다.

### 2. 모바일 가독성

- 글자 크기: 화면 폭의 5~8% 이상
- 명도 대비: 텍스트와 배경 명도 차이 4.5:1 이상 (WCAG AA)
- 한 컷에 한 핵심 메시지만 — 글자 잔뜩 X
- 폰트: 한글 가독성 좋은 sans-serif (Pretendard·Noto Sans KR 계열)

### 3. 제품 외관 일관성

- 12개 컷 전부에서 **같은 제품**이어야 함 — 색·로고·형태·재질 동일
- 제품 사진 reference가 있으면 무조건 활용
- 컷마다 제품이 다르게 나오면 reference 모드 작동 안 한 것 — 재생성

### 4. 마켓플레이스 컨벤션

스마트스토어·쿠팡 사용자가 익숙한 시각 패턴 따르기:

- 상단: 강한 후킹 헤드라인 (보통 흰색·검정·강조색)
- 중앙: 제품 또는 사용 장면 (큰 비주얼)
- 하단: 짧은 보조 카피·라벨·아이콘
- 여백 충분, 모바일 폭에 맞는 비율

### 5. 비율 정확성

| 섹션 | 비율 | 픽셀 |
|---|---|---|
| 정사각 (히어로·인증·후기) | 1:1 | 1024×1024 |
| 인스타·피드 | 4:5 | 1024×1280 |
| 모바일 표준 (제품·디테일) | 3:4 | 1024×1365 |
| 와이드 (Before/After·배너) | 16:9 | 1820×1024 |
| 스토리·릴스 | 9:16 | 1024×1820 |

## QA 체크리스트 (생성 후 모든 컷에 적용)

각 컷에 대해 다음을 확인:

```markdown
### Cut-01 (후킹) QA
- [x] 파일 생성됨 (output/section-01.png, 245KB)
- [x] 한글 텍스트 가독 (큰 글씨, 깨짐 없음)
- [x] 제품 외관 일치 (reference와 동일)
- [x] 모바일 가독성 (글자 크기 충분)
- [x] 비율 정확 (1024×1024)
- [x] 마켓플레이스 톤 (감성/실용 일치)
- [ ] 컴플라이언스 (의약품 오인 표현 X) ← 확인 필요
```

5/6 이상 통과면 OK. 미달이면 재생성.

## 절대 하지 말 것

❌ **공백 텍스트 박스만 있는 이미지** — "여기에 텍스트가 들어갑니다" 같은 placeholder 출력 금지.

❌ **순수 제품 사진만** — 상세페이지 컷은 디자인된 합성물이어야 함. 제품 사진만 띡 던지면 안 됨.

❌ **컨셉 아트 / 와이어프레임** — ASCII 또는 박스 일러스트는 기획 단계의 wireframe이지 최종 이미지가 아님.

❌ **영문이 한글 자리에 들어감** — 한글 카피로 요청했는데 영문이 나오면 실패.

❌ **사실 날조** — 가짜 인증마크, 가짜 별점, 가짜 가격, 가짜 후기 텍스트 X.

❌ **수동 텍스트 오버레이로 패치** — gpt-image-2가 한글 깨뜨리면 모델로 재생성. Photoshop/SVG로 텍스트 덧붙이기는 사용자가 명시 요청할 때만.

## 자동 검증 (Python 후처리)

`scripts/build_gallery.py` 가 갤러리 빌드시 자동으로 다음을 체크:

- 파일 존재 여부
- 파일 크기 (50KB 이상)
- 정상 PNG 형식 (Pillow로 open 가능)
- 비율 (요청 비율과 ±5% 일치)

체크 실패시 HTML 갤러리에 ⚠️ 표시 + 재생성 권장 메시지.
